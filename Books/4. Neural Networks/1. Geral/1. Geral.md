# 1. Neurons

## 1.1 What are Neurons

The fundamental unit of a neural network is the **artificial neuron** — a mathematical abstraction inspired by the biological neuron. Just as a neuron in the brain receives signals from other neurons, processes that information, and decides whether or not to fire, the artificial neuron receives input values, performs a simple computation, and produces an output.

Formally, given a set of inputs $x_1, x_2, \ldots, x_n$, the neuron computes:

$$z = w_1 x_1 + w_2 x_2 + \cdots + w_n x_n + b = \mathbf{w}^\top \mathbf{x} + b$$

where $\mathbf{w}$ is the weight vector and $b$ is the bias. The weights determine the relative importance of each input — and these are exactly the values the network learns during training.

## 1.2 How They Work (Similarity and Feature Extraction)

The operation $\mathbf{w}^\top \mathbf{x}$ is a **dot product** — and at its core, the dot product is a **similarity checker**. It measures how aligned the input vector $\mathbf{x}$ is with the weight vector $\mathbf{w}$:

- When the input closely resembles the pattern encoded in the weights → **high positive value**
- When they are orthogonal (unrelated) → **value near zero**
- When they point in opposite directions → **negative value**

### Example: Museum vs. Stadium

Suppose we are building a classifier that receives descriptions of places and must identify whether a given place is a **museum**. Our dataset contains two examples:

| Feature | Example A | Example B |
|---|---|---|
| Has permanent collection | 1 | 0 |
| Hosts guided tours | 1 | 0 |
| Has a ticket booth | 1 | 1 |
| Has a large open field | 0 | 1 |
| Has bleachers | 0 | 1 |

After training, the neuron responsible for detecting "museum" will have learned weights that reflect those characteristics — high values for features like *permanent collection* and *guided tours*, and low (or negative) values for *bleachers* and *open field*.

When Example A passes through:
$$z = (1 \times 0.9) + (1 \times 0.8) + (1 \times 0.5) + (0 \times -0.7) + (0 \times -0.8) = 2.2$$

When Example B passes through:
$$z = (0 \times 0.9) + (0 \times 0.8) + (1 \times 0.5) + (1 \times -0.7) + (1 \times -0.8) = -1.0$$

The neuron fires strongly for Example A and weakly (negatively) for Example B. **The dot product is the neuron asking: "how much does this input look like what I've learned to detect?"**

This is the central intuition: **each neuron learns to detect a specific pattern in the data**. A neuron may learn to respond strongly to a diagonal edge in an image, to a phonetic sequence in an audio signal, or to a combination of words in text. In this sense, neurons act as **feature extractors** — each one specialized in recognizing a particular structure in the input space.

## 1.3 Activation Functions

The result of the linear combination $z$ can take any real value — positive, negative, or zero. But not every value carries useful information. An absent feature should not contribute to the neuron's output; a strong negative signal may indicate precisely the absence of a pattern.

This is where the **activation function** comes in: it transforms $z$ into an output $a = \sigma(z)$, filtering or reshaping the signal before passing it forward. In essence, the activation function decides *what gets through* — present features are propagated, negative values are suppressed or transformed.

# 2. Layers

## 2.1 What are Layers

Isolated neurons have limited expressive power. The strength of neural networks emerges from **organizing neurons into layers** — groups of neurons that operate in parallel over the same input, whose outputs are collectively passed to the next group.

A layer transforms an input vector into an output vector: each neuron in the layer receives all the inputs, computes its activation value independently, and the collection of those activations forms the input to the next layer. Mathematically, a dense (or *fully connected*) layer computes:

$$\mathbf{a} = \sigma(W\mathbf{x} + \mathbf{b})$$

where $W$ is the layer's weight matrix, $\mathbf{b}$ the bias vector, and $\sigma$ the activation function applied element-wise.

## 2.2 Features of Features: What Layers Actually Learn

Each layer does not simply detect features from the raw input — **it detects features of features**. The deeper the layer, the more abstract the pattern it captures.

### Example: Recognizing a House

Consider a network trained on images of buildings. The task is to identify whether an image contains a house.

- **Layer 1** neurons detect **raw visual primitives**: horizontal lines, vertical lines, diagonal edges, color gradients. These are the simplest structures the pixels can form.

- **Layer 2** neurons combine those edges into **local shapes**: a right angle, a rectangular window frame, a triangular silhouette. These neurons are not looking at pixels — they are looking at *combinations of edges*.

- **Layer 3** neurons combine shapes into **object parts**: a roof (triangle sitting on top of a rectangle), a door (tall narrow rectangle at the base), a chimney (small rectangle on the roof slope). A "roof" neuron fires when the triangle-detector and the horizontal-line-detector both activate together in the right configuration.

- **Layer 4** neurons combine parts into a **concept**: the full house. This neuron fires when a roof, walls, windows, and a door are all detected in spatially coherent positions.

Notice that "roof" is a **feature of features**: it requires edges → shapes → arrangement. The network never explicitly programmed any of these concepts — it discovered them because they are the natural intermediate representations that make the final prediction possible.

The same principle applies beyond vision. In a network classifying places (like our museum example), a deeper layer might learn a neuron that detects "cultural institution" — a feature that fires when *museum*, *gallery*, *library*, and *theater* detectors all activate together. "Cultural institution" is then a feature of those features, which is itself a feature the output layer can use.

**This hierarchical composition is the core reason deep networks are powerful**: each additional layer can represent one more level of abstraction, building richer and richer descriptions of the input from the same raw data.

## 2.3 Input Layer, Hidden Layers, and Output Layer

A neural network is organized into three types of layers:

The **input layer** receives the raw data. Its neurons perform no transformation — they simply represent the features of the original data. For a 28×28 pixel image, the input layer would have 784 neurons; for a tabular feature vector with 20 columns, it would have 20.

The **hidden layers** are the computational core of the network. They are called "hidden" because their values are not directly observable in either the input or the output — they exist only as internal representations. This is where the network learns hierarchies of features: layers closer to the input capture simple patterns; deeper layers combine those patterns into complex abstractions. A network can have anywhere from one to hundreds of hidden layers — which is what defines so-called *deep learning* models.

The **output layer** produces the network's final prediction. Its structure depends on the task: a single neuron with sigmoid activation for binary classification, $k$ neurons with softmax for multiclass classification, or linear neurons for regression.
