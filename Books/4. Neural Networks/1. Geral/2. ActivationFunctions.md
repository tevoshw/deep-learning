# Activation Functions

Activation functions are one of the most important components of neural networks. Their main purpose is to introduce **nonlinearity**, allowing the network to learn complex relationships.

---

# Why Do We Need Activation Functions?

Suppose we stack multiple linear layers:

\[
y = W_3(W_2(W_1x))
\]

Since the composition of linear transformations is still linear:

\[
y = Wx
\]

Without activation functions, a deep network would behave like a single linear layer.

Activation functions break this limitation and allow the network to learn:

- XOR relationships;
- Images;
- Language;
- Audio;
- Complex feature interactions.

---

# Transforming the Feature Space

Activation functions transform the internal representation learned by the network.

Example:

```text
Linear Layer
↓
[-3, -1, 2, 5]

ReLU
↓
[0, 0, 2, 5]
````

As activations pass through layers, the feature space becomes progressively more separable and meaningful.

---

# Negative Values as Noise

Negative activations are not necessarily noise.

They may represent:

* contrary evidence;
* absence of a feature;
* inhibitory information.

However, some architectures assume that negative contributions are less useful and discard them to simplify learning.

> Negative values can be treated as unhelpful contributions, contrary evidence, or even "noise", depending on the architecture.

---

# Probabilistic Output Functions

---

## Sigmoid

[
\sigma(x)=\frac{1}{1+e^{-x}}
]

Range:

```text
0 → 1
```

Example:

```text
-10 → 0.0000
0   → 0.5000
10  → 0.9999
```

### Advantages

* Interpretable probabilities.
* Smooth transitions.

### Drawbacks

* Saturation.
* Vanishing gradients.

### Use Cases

* Binary classification.

---

## Softmax

Transforms a vector into a probability distribution.

Example:

Input:

```text
[1, 2, 3]
```

Output:

```text
[0.09, 0.24, 0.67]
```

Properties:

* Values sum to 1.
* Largest value receives highest probability.

### Use Cases

* Multi-class classification.
* Next-token prediction.

---

## Tanh

[
\tanh(x)
]

Range:

```text
-1 → 1
```

Example:

```text
-10 → -1
0 → 0
10 → 1
```

### Advantages

* Zero-centered.

### Drawbacks

* Saturation.
* Vanishing gradients.

---

# Deterministic Activation Functions

---

## ReLU

[
f(x)=\max(0,x)
]

### Philosophy

> Negative values are probably noise.

Example:

```text
[-3, -1, 2, 5]

↓

[0, 0, 2, 5]
```

### Advantages

* Fast.
* Sparse activations.
* Simple.

### Drawbacks

* Information loss.
* Dead neurons.

### Use Cases

* CNNs.
* MLPs.

---

## Leaky ReLU

[
f(x)=
\begin{cases}
x,&x>0\
\alpha x,&x\le0
\end{cases}
]

Usually:

```text
α = 0.01
```

### Philosophy

> Most negatives are noise, but preserve a small fraction.

Example:

```text
[-3, -1, 2]

↓

[-0.03, -0.01, 2]
```

### Advantages

* Prevents dead neurons.

### Drawbacks

* Requires choosing α.

### Use Cases

* ReLU replacement.

---

## ELU

### Philosophy

> Negative evidence contains useful information.

### Advantages

* Rich information flow.
* Zero-centered activations.

### Drawbacks

* Exponential computation.

### Use Cases

* Deep MLPs.

---

## SELU

### Philosophy

> Preserve information while stabilizing the network.

SELU attempts to keep:

```text
Mean ≈ 0
Variance ≈ 1
```

This behavior is called:

### Self-Normalization

### Advantages

* Stable activations.
* Reduced need for normalization layers.

### Drawbacks

* Requires specific initialization.

### Use Cases

* Self-Normalizing Neural Networks.

---

## GELU

### Philosophy

> Negative values may contain information; attenuate them smoothly.

Example:

```text
-2 → -0.05
-1 → -0.16
1 → 0.84
2 → 1.95
```

### Advantages

* Smooth gradients.
* Excellent Transformer performance.

### Drawbacks

* Higher computational cost.

### Use Cases

* BERT.
* GPT-2.
* GPT-3.
* Vision Transformers.

---

## SiLU (Swish)

[
f(x)=x\sigma(x)
]

### Philosophy

> Every activation should contribute according to its importance.

The Sigmoid acts like an adaptive coefficient.

Example:

```text
-2 → -0.24
-1 → -0.27
1 → 0.73
2 → 1.76
```

### Advantages

* Rich information flow.
* Adaptive gating.

### Drawbacks

* Less sparse representations.

### Use Cases

* EfficientNet.
* Modern architectures.

---

# Preservation of Negative Information

| More → Less |
| ----------- |
| SELU / ELU  |
| SiLU        |
| GELU        |
| Leaky ReLU  |
| ReLU        |

---

# Preservation of Positive Information

| More → Less             |
| ----------------------- |
| SELU                    |
| ReLU / Leaky ReLU / ELU |
| GELU                    |
| SiLU                    |
| Sigmoid / Tanh          |

---

# Common Architectures

| Activation | Typical Usage             |
| ---------- | ------------------------- |
| ReLU       | CNNs, MLPs                |
| Leaky ReLU | ReLU replacement          |
| ELU        | Deep MLPs                 |
| SELU       | Self-Normalizing Networks |
| GELU       | Transformers              |
| SiLU       | EfficientNet              |
| SwiGLU     | Modern LLMs               |

---

# Evolution

```text
ReLU
↓
Leaky ReLU
↓
ELU
↓
SELU
↓
GELU
↓
SiLU
↓
SwiGLU
```

Each new activation attempts to preserve more information, improve gradient flow, and provide richer feature representations.
