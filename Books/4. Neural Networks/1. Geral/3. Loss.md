# Loss Functions in Deep Learning & Machine Learning

## What is a Loss Function?

A loss function measures how wrong the model's predictions are. The training process minimizes this value by adjusting the model's weights via backpropagation.

$$\text{Training} = \underset{\theta}{\arg\min} \ L(y, \hat{y})$$

> **Key insight:** Depending on the loss function, it can pull the error much more aggressively, penalizing the model heavily for large mistakes — forcing the data to adapt to outliers and noisy samples. Choosing the wrong loss can make your model overfit to noise or ignore important patterns entirely.

---

## 1. Regression Losses

Used when the output is a continuous value (price, temperature, etc.).

### MSE — Mean Squared Error (L2 Loss)

$$MSE = \frac{1}{n}\sum_{i=1}^{n}(\hat{y}_i - y_i)^2$$

```python
nn.MSELoss()
F.mse_loss(output, target)
```

Squares the error — an error of 10 becomes 100, an error of 100 becomes 10,000. A single outlier can dominate the entire loss and pull the weights aggressively to compensate for it. The model bends itself to not miss any point, even noise.

---

### MAE — Mean Absolute Error (L1 Loss)

$$MAE = \frac{1}{n}\sum_{i=1}^{n}|\hat{y}_i - y_i|$$

```python
nn.L1Loss()
F.l1_loss(output, target)
```

Linear penalty — all errors have equal "political weight" in the gradient. The model is much less sensitive to outliers. However, the constant gradient near the minimum (±1) can cause instability during convergence.

---

### Huber Loss

$$L_\delta(e) = \begin{cases} \frac{1}{2}e^2 & \text{if } |e| \leq \delta \\ \delta\left(|e| - \frac{1}{2}\delta\right) & \text{if } |e| > \delta \end{cases}$$

```python
nn.HuberLoss(delta=1.0)
F.huber_loss(output, target, delta=1.0)
```

Behaves like L2 for small errors (smooth gradient near minimum) and like L1 for large errors (robust to outliers). The best of both worlds — but requires tuning `δ`.

> ⚠️ A `δ` too large degrades to pure MSE. Too small degrades to pure MAE.

---

### RMSE — Root Mean Squared Error

$$RMSE = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(\hat{y}_i - y_i)^2}$$

```python
# No native PyTorch class — compute manually
rmse = torch.sqrt(nn.MSELoss()(y_pred, y_true))
```

Same sensitivity as MSE, but the result is in the same unit as `y` — easier to interpret.

---

### When to Use Each Regression Loss

| Scenario | MSE | MAE | Huber | RMSE |
|---|---|---|---|---|
| Clean data, no outliers | ✅ | ✅ | ✅ | ✅ |
| Severe outliers | ❌ | ✅ | ⚠️ | ❌ |
| Moderate outliers | ⚠️ | ⚠️ | ✅ | ⚠️ |
| Same unit as target | ❌ | ✅ | ❌ | ✅ |
| Stable gradients near minimum | ✅ | ❌ | ✅ | ✅ |
| No hyperparameter tuning | ✅ | ✅ | ❌ | ✅ |
| Safe default (unknown data) | ❌ | ❌ | ✅ | ❌ |

> ⚠️ **Legend:** ✅ Recommended — ⚠️ Use with caution — ❌ Not ideal

## 2. Classification Losses

Used when the output is a discrete class (cat, dog, fraud/not-fraud, etc.).

### Cross-Entropy Loss

$$CE = -\sum_{c=1}^{C} y_c \log(\hat{y}_c)$$

Since labels are one-hot, this collapses to:

$$CE = -\log(\hat{y}_{correct\ class})$$

```python
nn.CrossEntropyLoss()          # already includes LogSoftmax internally
F.cross_entropy(output, target)
```

The model outputs logits → `CrossEntropyLoss` applies `LogSoftmax` internally → computes `-log` of the correct class probability.

| Correct class probability | Loss |
|---|---|
| 0.99 | ~0.01 ✅ |
| 0.70 | ~0.35 |
| 0.50 | ~0.69 |
| 0.10 | ~2.30 ❌ |
| 0.01 | ~4.60 ❌ |

> ⚠️ Never apply `Softmax` manually in the last layer when using `CrossEntropyLoss` — it already does it internally. Applying it twice will produce wrong results.

---

### BCE — Binary Cross-Entropy

$$BCE = -[y \cdot \log(\hat{y}) + (1-y) \cdot \log(1-\hat{y})]$$

```python
nn.BCEWithLogitsLoss()   # ✅ includes Sigmoid internally
nn.BCELoss()             # ⚠️ you must apply Sigmoid manually before
```

Special case of Cross-Entropy for binary problems. Uses a single output neuron instead of a vector of C classes. The probability of class 0 is implicit: `1 - prob`.

> ⚠️ Always prefer `BCEWithLogitsLoss` over `BCELoss` — it is numerically more stable by combining Sigmoid + log in a single operation.

---

### NLL — Negative Log Likelihood

$$NLL = -\log P(y | x, \theta)$$

```python
log_probs = nn.LogSoftmax(dim=1)(logits)
nn.NLLLoss()(log_probs, target)
```

Mathematically identical to Cross-Entropy. The difference is that `NLLLoss` expects `log_probs` already computed, while `CrossEntropyLoss` accepts raw logits and does `LogSoftmax` internally.

```
CrossEntropyLoss  =  LogSoftmax  +  NLLLoss
```

Use `NLLLoss` when you already have `log_probs` from another computation (e.g. beam search, RL) and want to avoid recomputing `LogSoftmax`.

## 3. Class Imbalance in Classification

> ⚠️ **Critical problem:** When classes are heavily imbalanced (e.g. 9000 dogs vs 100 frogs), the loss from the majority class dominates training. The model learns to predict the majority class and ignores rare ones — achieving high accuracy but being useless in practice. Never use accuracy as a metric in imbalanced datasets.

### Solution 1 — Class Weights in the Loss

```python
# inversely proportional to class frequency
weights = torch.tensor([0.1, 1.0, 9.0])  # dog, cat, frog
loss = nn.CrossEntropyLoss(weight=weights)

# compute automatically with sklearn
from sklearn.utils.class_weight import compute_class_weight
weights = compute_class_weight('balanced', classes=np.array([0,1,2]), y=y_train)
weights = torch.tensor(weights, dtype=torch.float32)
```

For BCE, use `pos_weight` — the ratio between negatives and positives:

```python
pos_weight = n_negatives / n_positives  # e.g. 9000/100 = 90.0
loss = nn.BCEWithLogitsLoss(pos_weight=torch.tensor([90.0]))
```

## 4. Full Summary

| Loss | Task | Outlier Sensitive | Softmax/Sigmoid Built-in | PyTorch |
|---|---|---|---|---|
| MSE | Regression | High | — | `nn.MSELoss()` |
| MAE | Regression | Low | — | `nn.L1Loss()` |
| Huber | Regression | Moderate | — | `nn.HuberLoss(delta)` |
| RMSE | Regression | High | — | `torch.sqrt(mse(...))` |
| Cross-Entropy | Multiclass | — | ✅ LogSoftmax | `nn.CrossEntropyLoss()` |
| BCE | Binary | — | ✅ Sigmoid | `nn.BCEWithLogitsLoss()` |
| NLL | Multiclass | — | ❌ you apply | `nn.NLLLoss()` |
| KL Divergence | Soft labels | — | ❌ you apply | `nn.KLDivLoss()` |
| Focal Loss | Imbalanced | — | ✅ Sigmoid | `sigmoid_focal_loss()` |
