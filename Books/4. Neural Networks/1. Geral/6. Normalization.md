# Normalization

## What is it and why use it

Normalization rescales values to a consistent distribution. It serves two purposes:

**Scale** — prevents large input values (e.g. 10,000) from dominating gradients, causing unstable updates.

**Stability** — in deep networks, activation distributions drift across layers. Even with small values (0–10), after 96 layers the distribution is completely different from layer 1. Normalization resets mean and std at each layer, keeping training stable regardless of depth.

The direction (meaning) of vectors is preserved — only the magnitude is rescaled.

---

## Input normalization

Applied to raw data before feeding the network.

### Min-Max
Scales values to [0, 1]. Sensitive to outliers.
```python
x' = (x - min) / (max - min)
```

### Z-score (Standardization)
Mean = 0, std = 1. More robust to outliers.
```python
x' = (x - μ) / σ
```

---

## Internal normalization (activations)

Applied inside the network between layers.

### Batch Norm
Normalizes across the **batch dimension** per channel (second dim).

```python
# always pass C (second dim)
x = (N, C)          → nn.BatchNorm1d(C)
x = (N, C, L)       → nn.BatchNorm1d(C)
x = (N, C, H, W)    → nn.BatchNorm2d(C)
x = (N, C, D, H, W) → nn.BatchNorm3d(C)
```

- Depends on batch size — noisy with small batches
- Different behavior in train vs eval (`model.eval()` uses running stats)
- Best for: CNNs

### Layer Norm
Normalizes across the **last dimension(s)** within each sample independently.

```python
# pass the shape of the last dim(s)
x = (N, C)          → nn.LayerNorm(C)
x = (N, L, C)       → nn.LayerNorm(C)
x = (N, C, H, W)    → nn.LayerNorm([C, H, W])
```

- Independent of batch size — identical behavior at batch=1 or batch=512
- Same behavior in train and eval
- Best for: Transformers, LLMs

```
Batch Norm → always C (second dim)
Layer Norm → always the last dim(s)
```

---

## Why Layer Norm in Transformers

Transformers use `(N, seq_len, d_model)`. Each token has a `d_model`-dimensional embedding — Layer Norm normalizes those values within each token independently, preserving relative distances between tokens while keeping the distribution stable across layers.

Also works correctly at batch=1 (autoregressive inference, token by token) — Batch Norm would need running statistics and behaves differently in that regime.

---

## Learnable parameters

Both Batch Norm and Layer Norm apply `gamma` (scale) and `beta` (shift) after normalization:

```python
output = gamma * normalized + beta
```

Mean=0 and std=1 is not universally optimal. Each layer learns different features, and the activation function behaves differently depending on the distribution it receives.

For example, a shallow layer detecting edges may work fine with mean=0, std=1 — activations are sparse and the default distribution fits. A deeper layer detecting complex textures may need a shifted distribution (e.g. mean=0.5, std=1.5) to keep values in the active region of GELU and avoid dead gradients.

`gamma` and `beta` are learnable parameters updated by backprop — the model finds the optimal distribution per layer automatically:
layer 1 (edges):    gamma=1.0, beta=0.0  →  mean=0,   std=1

layer 5 (textures): gamma=1.5, beta=0.5  →  mean=0.5, std=1.5

This gives the model flexibility to learn the ideal distribution per layer without losing the stability that normalization provides

## Quick reference

| | Batch Norm | Layer Norm |
|---|---|---|
| Normalizes over | batch (per channel) | features (per sample) |
| PyTorch param | `num_features = C` | `normalized_shape = last dim(s)` |
| Batch size dependency | yes | no |
| Train vs eval | different | identical |
| Use case | CNNs | Transformers |
